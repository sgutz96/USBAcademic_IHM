# README - Interacción Humano-Máquina

## 📋 Descripción del Curso

Curso de **Interacción Humano-Máquina** enfocado en el diseño y desarrollo de interfaces de usuario efectivas, accesibles y centradas en el usuario. El programa combina teoría de diseño UI/UX con implementación práctica usando tecnologías web modernas.

## 🎯 Objetivos del Curso

- Comprender los principios fundamentales del diseño de interfaces
- Aplicar patrones de diseño y buenas prácticas de UI/UX
- Desarrollar interfaces web accesibles y responsivas
- Implementar interacciones dinámicas con JavaScript
- Integrar elementos 3D en experiencias web modernas
- Evaluar y mejorar la usabilidad de interfaces

## 📖 Módulos Temáticos

### **Módulo 1-3: Fundamentos**
- Introducción a IHM y patrones de diseño
- HTML semántico y estructura web
- Diseño Centrado en el Usuario (DCU)
- Modelo MVC
- Psicología cognitiva aplicada (Ley de Fitts, Ley de Hick)
- CSS básico: colores, tipografías, selectores

### **Módulo 4-6: Diseño y Accesibilidad**
- Arquitectura de la Información
- Accesibilidad Web (WCAG)
- CSS Layout: Flexbox y Grid
- Diseño responsive con Media Queries
- Wireframes y prototipos
- Heurísticas de Nielsen
- Styleguides y sistemas de diseño

### **Módulo 7-10: Interactividad**
- Accesibilidad avanzada (WCAG 2.1)
- Formularios accesibles
- JavaScript: variables, tipos de datos, eventos
- Programación Orientada a Objetos
- Manipulación del DOM
- Contenido dinámico

### **Módulo 11-13: Componentes Avanzados**
- Diseño responsive avanzado
- Componentes UI reutilizables
- Menús interactivos
- Evaluación heurística
- Pruebas de usabilidad
- Refactorización y mejores prácticas

### **Módulo 14-16: 3D e Integración**
- Introducción a gráficos 3D (Three.js)
- Escenas 3D básicas
- Integración de elementos 3D en interfaces web
- Iteración y mejora continua
- Proyecto final integrador

## 🛠️ Tecnologías Utilizadas

- **HTML5**: Estructura semántica
- **CSS3**: Estilos, Flexbox, Grid, Media Queries
- **JavaScript**: Interactividad y manipulación del DOM
- **Three.js**: Gráficos 3D
- **Figma/Sketch/Adobe XD**: Prototipado
- **Lighthouse/WAVE**: Auditoría de accesibilidad

## 📝 Metodología

Cada semana incluye:
- **Ejercicio Práctico**: Aplicación inmediata de conceptos
- **Tarea**: Investigación y profundización teórica
- **Entregas de Corte**: Evaluaciones en semanas 6, 11 y 16

## ✅ Sistema de Evaluación

- **Corte 1 (Semana 6)**: Diseño visual y heurísticas + Styleguide
- **Corte 2 (Semana 11)**: Diseño responsive avanzado + Menú interactivo
- **Corte 3 (Semana 16)**: Proyecto final completo

## 🎓 Competencias Desarrolladas

1. **Diseño UI/UX**: Crear interfaces intuitivas y estéticamente agradables
2. **Accesibilidad**: Desarrollar sitios web inclusivos (WCAG 2.1)
3. **Desarrollo Frontend**: HTML, CSS y JavaScript moderno
4. **Pensamiento de Usuario**: Aplicar DCU y psicología cognitiva
5. **Evaluación de Usabilidad**: Realizar auditorías y pruebas heurísticas
6. **Tecnologías Emergentes**: Integrar gráficos 3D en web
